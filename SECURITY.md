# Security policy

Security fixes target the latest released version. Older 0.x versions do not
have a separate maintenance guarantee. Use supported Django releases and their
latest security patches.

Report vulnerabilities through GitHub's private reporting form:
https://github.com/hitenjadeja/django-admin-htmx/security/advisories/new

Include affected versions, reproduction steps, impact and a minimal example.
Do not include real credentials or production data. Please avoid public issues
for undisclosed vulnerabilities. Response timing depends on maintainer availability.

The example settings, seeded passwords and generated test projects are local
development fixtures. They are not production deployment configurations.
